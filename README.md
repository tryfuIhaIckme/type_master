# TypeMaster — Соревновательная платформа скоропечатания

Веб-приложение для тренировки навыка слепой печати, мониторинга личной статистики и соревнований между пользователями. Сервис включает режим тестирования по связным текстам, генератор случайных лексических последовательностей, аркадный режим «Падающие слова», а также глобальную таблицу лидеров.

Проект разработан в рамках курсовой работы по дисциплине «Разработка веб-приложений» (Московский Политех, кафедра «Инфокогнитивные технологии»).

---

## Основной функционал

- **Тестирование печати:** интерактивный ввод с посимвольной подсветкой ошибок и расчетом метрик в реальном времени (WPM, точность %, количество ошибок). Перезапуск теста по клавише `Tab`.
- **Режимы тренировки:**
  - Набор текстов из библиотеки (русский и английский языки, уровни сложности: easy, medium, hard).
  - Набор случайных слов (10, 20 или 40 слов).
  - Аркадная игра «Падающие слова» с ограничением по времени и контролем жизней.
- **Соревновательный модуль:**
  - Глобальная таблица лидеров (топ-50 результатов по WPM).
  - Личный кабинет с агрегированной аналитикой (средняя скорость, личный рекорд, общее число попыток).
  - Экспорт истории прохождений в формат CSV.
- **Администрирование контента:** добавление текстов через веб-форму или загрузка файлов формата `.txt` (доступно для роли администратора).
- **Интерфейс:** адаптивная верстка с поддержкой переключения светлой и темной тем.

## Стек технологий

- **Backend:** Python 3.10+, Flask, Flask-SQLAlchemy (ORM), Flask-Login, Flask-Bcrypt, Flask-WTF, Flask-Migrate.
- **Frontend:** HTML5, CSS3 (CSS Variables), JavaScript (Vanilla ES6+), Bootstrap 5.
- **База данных:** SQLite (для разработки) / совместимость с PostgreSQL.
- **Серверная часть:** WSGI-сервер Gunicorn.

## Установка и локальный запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/typemaster.git
cd typemaster
```

### 2. Настройка виртуального окружения
Для Linux/macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```

Для Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python run.py
```
После запуска сервис доступен в браузере по адресу: `http://127.0.0.1:5000/`.

## База данных

В приложении используется реляционная модель данных:
- `User` — учетные записи пользователей и флаг роли администратора.
- `Text` — тренировочные тексты, метаданные языка и сложности.
- `TestSession` — сессия попытки прохождения теста (связь $1:M$ с пользователем и текстом).
- `Result` — итоговые метрики заезда: WPM, точность, число ошибок, дата (связь $1:1$ с сессией).

## Развертывание (Production)

Запуск приложения в производственной среде осуществляется через WSGI-сервер Gunicorn:

```bash
gunicorn run:app --workers 3 --bind 0.0.0.0:8000 --timeout 120
```

Для обработки SSL-сертификатов и статических файлов перед Gunicorn настраивается обратный прокси-сервер (Nginx).
